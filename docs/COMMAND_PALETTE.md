# Command palette and keyboard shortcuts

Press Ctrl+K from anywhere in the platform shell to open the command palette.
It searches navigation destinations, collections, recent conversations, and
recent outputs. The global search overlay is opened from the header and covers
sources, conversations, outputs, collections, and tags.

Shortcuts:

- Ctrl+K — command palette
- Ctrl+N — new chat/workspace
- Ctrl+Shift+U — open workspace upload
- Ctrl+S — dispatch save-output for the active output workflow
- Escape — close overlays and dialogs
- Arrow Up/Down and Enter — select and open options

Overlays use modal semantics, move focus to their first control, preserve a
visible active option, and return focus to the previously focused element when
closed. The existing skip link remains available for keyboard users.
