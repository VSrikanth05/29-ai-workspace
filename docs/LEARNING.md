# Learning tools

Flashcards, Quiz, and Study Guide live in the existing AI Studio Learn module
and use the AI Gateway, context builder, conversations, grounding, and output
persistence.

Flashcard responses are validated JSON containing question, answer, difficulty,
and category. The viewer supports reveal, navigation, and shuffle. Quiz responses
are validated mixed-format questions. Normalized exact answers are auto-graded;
review shows the correct answer and explanation.

Counts are limited to 5, 10, or 20 and difficulty to easy, medium, or hard.
Study Guides are Markdown with the six approved sections. All three output types
are saved, reopenable, regeneratable, and exportable as Markdown or JSON.
